## Overview

This repository contains structured notes, annotated examples, and exercises
covering the C programming language from foundational concepts to advanced topics.
The material is organized sequentially, following the curriculum structure of the
Programiz C Programming tutorial, and is intended for students seeking a rigorous
introduction to systems-level programming.

C is one of the most influential programming languages in computer science. It
serves as the foundation for operating systems, compilers, embedded systems, and
firmware development. Mastering C provides a solid understanding of how programs
interact with hardware and memory — knowledge that transfers directly to languages
such as C++, Java, and Python.

## Prerequisites

- Basic understanding of logic and mathematics
- A C compiler: [GCC](https://gcc.gnu.org/) on Linux/macOS, or [MinGW](https://www.mingw-w64.org/) on Windows
- Alternatively, use the [Programiz Online C Compiler](https://www.programiz.com/c-programming/online-compiler/) to run examples directly in the browser

### Compiling and Running a Program
```bash
gcc filename.c -o output
./output
```
